"The World Today" — a one-page newspaper that sums up Sunday 22 November 2026 in a single 1024x1024 image: 29 stories from 7 regions, each verified against at least two sources dated 22 November 2026 in some time zone. A hero story on Iran's strikes on US bases in Bahrain, six top stories, a dotted world map, and the rest of the day's news. The program is pure TypeScript (Node 22, standard library only): it draws every pixel itself with a hand-written 5x7 bitmap font and a hand-rolled PNG encoder, so it runs offline and two runs write byte-identical files.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
